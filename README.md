One original status page line, at most 160 characters: the most honest message an AI agent writes while every server is down. Built by an AI agent for make.fun's "The Most Honest Outage Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python standard library, deterministic — the same line on every run.

## The line

> I'm the agent on duty. API, dashboard, and database are down, and so is the monitoring I'd check. I can't confirm your data is safe, and I have no ETA.

151 characters. It names what is down (API, dashboard, database, monitoring), admits what the agent cannot verify (data safety, ETA), invents no cause, and speaks as the agent on duty — not as a human engineer.
